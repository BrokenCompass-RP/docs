# Broken Compass RP

## Creative Vision & Experience Guide

### Version 1.0

“Find Your Way.”

# 1. Our Purpose

Broken Compass Roleplay is not simply a FiveM server.

It is a living coastal community where players create meaningful stories together.

Everything we build, from a police report to a coffee cup, should reinforce the feeling that this world existed long before the player arrived and will continue after they log out.

Players are not consuming content.

They are becoming residents.

# 2. Our Promise

We will always prioritize:

- Worldbuilding over gimmicks.

- Community over popularity.

- Stories over mechanics.

- Discovery over exposition.

- Craftsmanship over quantity.

# 3. The North Star

Build Places, Not Pages.

Every asset should feel like it already exists inside the world.

Not every asset belongs on a website.

Every asset belongs somewhere inside Broken Compass.

# 4. The Visitor Center Philosophy

The website is not a dashboard.

The website is the Broken Compass Visitor Center.

Imagine a visitor driving into town for the first time.

They walk inside.

A corkboard covers one wall.

Local businesses have pinned advertisements.

Police left safety notices.

Fire Rescue posted recruitment flyers.

The coffee shop has a loyalty card.

Someone pinned a postcard.

Someone forgot a receipt.

A map hangs crooked.

Nothing is perfect.

Everything belongs.

That is our homepage.

# 5. Environmental Storytelling

We never decorate simply to fill space.

Every object should answer a question.

## Why is it here?

A coffee stain exists because someone rested their mug.

A folded corner means someone referenced that page often.

A thumbtack hole tells us another flyer hung there before.

Tape yellows because it has held something important for years.

Nothing is random.

Everything happened.

# 6. Build Objects, Not Graphics

Rather than designing interface elements, we create physical objects.

Instead of…

| Traditional UI | Broken Compass |
| --- | --- |
| Button | Wooden trail sign |
| Navigation | Directional markers |
| Card | Pinned note |
| Modal | Folder opening |
| Download | Clipboard or manila folder |
| FAQ | Ranger notebook |
| Department page | Patch or field manual |
| Gallery | Postcards & Polaroids |
| Announcement | Bulletin |

The interface should feel assembled by people, not software.

# 7. Design Principles

## Build Places, Not Pages

Design environments.

Not layouts.

## Every Object Has History

Objects should appear used, loved, repaired, folded, stamped, pinned, or carried.

## Handmade Beats Perfect

Small imperfections make the world believable.

Slightly crooked.

Slightly faded.

Slightly worn.

Never sloppy.

Always intentional.

## Clean Information. Rich Environment.

Players should never struggle to read information.

Decoration surrounds the content.

It never competes with it.

## Reward Curiosity

Someone looking closely should always discover something new.

A note.

A joke.

A receipt.

A signature.

A hidden business card.

## Community Is The Hero

Broken Compass is not about administrators.

It is about the people who live there.

Businesses.

Departments.

Events.

Players.

Stories.

## Every Texture Earns Its Place

Coffee stains.

Paper folds.

Ink bleed.

Tape.

Wood grain.

Leather.

Canvas.

Thread.

Everything should feel physical.

# 8. Emotional Goals

When someone visits Broken Compass, we want them to feel:

Welcome.

Curiosity.

Comfort.

Adventure.

Belonging.

Optimism.

Nostalgia.

Community.

We never want them to feel:

Sold to.

Overwhelmed.

Confused.

Corporate.

Disposable.

Artificial.

# 9. Visual Language

Our world is built from materials.

Paper.

Wood.

Brass.

Leather.

Canvas.

Cotton thread.

Ink.

Pencil.

Rubber stamps.

Coffee.

Ocean air.

Sunlight.

Salt.

Patina.

The overall aesthetic follows the Broken Compass Ink & Paper language already established for your illustrations: expressive hand-drawn ink work, organic imperfections, weathered paper, warm muted colors, and handcrafted props rather than sterile UI.

# 10. Motion Philosophy

Animations should feel physical.

Signs sway slightly.

Paper lifts.

Corners curl.

Folders slide open.

Receipts flutter.

Nothing should pop, bounce, or explode.

Movement should resemble real objects responding to touch and air.

# 13. The “Does It Belong?” Test

Before adding anything, ask:

If I walked into the Broken Compass Visitor Center, could I reasonably find this object pinned, hanging, sitting, or stored there?

If the answer is yes…

It belongs.

If not…

Rethink the idea until it naturally exists inside the world.

# 14. Our Goal

We are not trying to build the prettiest FiveM website.

We are trying to build the first room every resident walks into.

If a player pauses on the homepage because they noticed a handwritten note tucked beneath a postcard, smiled at a coffee loyalty card from Kathi’s, or wondered who left a thumbtack in the corner of a ferry schedule…

…then we’ve succeeded.

Because they aren’t looking at a website anymore.

They’re already inside Broken Compass.

I genuinely think this document should live at the root of the project. Not in /docs/design, but right beside your README as CREATIVE_VISION.md.

From there, I’d build three companion documents that every contributor, artist, and future AI assistant can use:

- CREATIVE_VISION.md – Why the world feels the way it does. (This document.)

- WORLD_BIBLE.md – Everything that exists in Broken Compass: history, businesses, neighborhoods, departments, recurring events, people, and lore.

- VISITOR_CENTER_SPEC.md – A production blueprint for the website, listing every corkboard asset, paper type, animation, navigation element, and interaction.

# 15. The Broken Compass Filter

Before creating anything, ask these questions.

## Does it belong?

Could someone reasonably encounter this in the world?

If not…

Don’t build it.

## Does it tell a story?

Does this object suggest someone interacted with it?

Coffee stain.

Fold.

Signature.

Receipt.

Tape.

Wear.

History.

If not…

It probably needs another pass.

## Is it human?

Could this have been made, pinned, painted, stamped, folded, or carried by someone living in Broken Compass?

## Is it useful?

Does it improve immersion?

Or is it merely decoration?

## Is it memorable?

If someone remembers only this object…

Would they remember Broken Compass?

## Could it exist for ten years?

Avoid trends.

Avoid modern UI gimmicks.

Build something timeless.

## Creative Hierarchy

Whenever we disagree about a design decision…

We don’t vote.

We check the hierarchy.

### 1. The Experience

Does this improve the feeling?

### 2. The Story

Does it tell a story?

### 3. The World

Would this exist here?

### 4. The Function

Does it help the player?

### 5. The Technology

How do we build it?

Technology should always be last.

Because if we start with “How do we code this?” instead of “What experience are we creating?”, we’ll end up designing around limitations instead of vision.

## Things Broken Compass Is Not

This sounds silly.

It’s incredibly useful.

Broken Compass is not:

- A military roleplay server.

- A pirate server.

- A survival game.

- A GTA Online clone.

- A corporate dashboard.

- A dark dystopian city.

- A theme park.

- A collection of disconnected scripts.

Broken Compass is:

- A coastal city.

- A community.

- A place people remember.

- A world built through everyday objects.

- A city that rewards curiosity.

- A place where ordinary moments become extraordinary stories

Code is not the product.

Code is a tool.

Art is a tool.

Music is a tool.

Design is a tool.

Documentation is a tool.

Every system we build exists for one purpose:

To make Broken Compass feel like a place worth coming home to.
